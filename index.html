Why Initialize with a README?

An empty Git repository has zero commits and therefore no branches yet. Checking "Add a README file" automatically creates your first commit and establishes the default main branch so you can branch off it immediately.

What is a Diff?

A diff highlights the exact differences between two branches. Green lines (+) are additions, while red lines (-) are removals.

What About Merge Conflicts?

If two branches edit the exact same lines of a file, GitHub pauses the merge and asks you to resolve the conflict manually before clicking Merge pull request.

GitHub Flow Quick-Reference

  1. 1. Create Branch: Always branch off main with a descriptive name (e.g., readme-edits).
  2. 2. Make Commits: Save focused, atomic changes with clear commit messages explaining why.
  3. 3. Open Pull Request: Propose merging your branch into main and inspect the color-coded diff.
  4. 4. Review & Discuss: Collaborators review changes, leave comments, or push follow-up commits.
  5. 5. Merge & Delete: Merge into main and delete the temporary branch to keep the repo clean.

Free Hosting

This workbook is engineered as a single, zero-dependency index.html file ready for instant static hosting:

  1. Create a Public repository on GitHub (e.g., github-flow-workbook).
  2. Upload this file as index.html into the root of your main branch.
  3. Go to Settings → Pages in your repository.
  4. Under Build and deployment → Source, select Deploy from a branch.
  5. Choose branch main and folder / (root), then click Save.
  6. Within ~60 seconds, your live workbook URL (https://username.github.io/github-flow-workbook/) will appear at the top of the Pages settings!
